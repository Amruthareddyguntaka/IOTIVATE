# IOTIVATE
![IOTIVATE Project](WhatsApp%20Image%202026-09-23%20at%209.52.09%20PM.jpeg)

IoT-based electrical appliance repair and issue identification project using ESP32.

## About the Project

IOTIVATE is an IoT project developed to demonstrate a simple way of identifying electrical appliance issues and indicating their status using an ESP32-based system.

## Technologies

- ESP32
- Arduino IDE
- Embedded C/C++

## Hardware Components

- ESP32 DevKit V1
- Push buttons
- LEDs
- Resistors
- Breadboard
- Jumper wires

## Project Status

Prototype completed and demonstrated as a college IoT project.

## Future Scope

The system can be further improved with sensors, a mobile or web interface, notifications, and additional appliance monitoring features.
